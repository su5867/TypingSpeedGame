# Typing Speed Game ⌨️⚡

This is a simple **Java-based Typing Speed Game** developed using **Eclipse IDE**. The game measures how fast a user can type a given sentence within a limited time.

## 🚀 Features

- Random sentence generator
- Real-time typing speed measurement
- Words per minute (WPM) calculation
- Accuracy tracking
- Java Swing GUI interface

## 🛠 Technologies Used

- Java SE (JDK 22)
- Java Swing (for GUI)
- Eclipse IDE
